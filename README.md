# 🎲 Dice Roll Game | Моя первая JS-игра

**первая игра на JavaScript** — простая, но увлекательная игра в кости, где можно бросить виртуальный кубик и испытать удачу! ✨

## 🌟 О проекте

Этот проект создан для практики основ JavaScript:
- Работа с DOM
- Генерация случайных чисел
- Обработка событий
- Обновление интерфейса в реальном времени

## 🎯 Как играть?

1. **Нажми кнопку "Бросить кубик"** 👇
2. **Смотри результат** 👀
3. **Попробуй снова!** 🔄

Просто, но затягивает! 😄

## 🛠 Технологии

- HTML5
- CSS3
- JavaScript (ES6)
